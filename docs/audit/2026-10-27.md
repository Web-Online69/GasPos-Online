## Metode dan batas bukti
Salinan skema, fungsi public/private, view, constraint, FK, trigger dan kebijakan RLS diambil tanpa menyalin transaksi atau akun produksi. PGlite menjalankan PostgreSQL lokal di memori. auth.uid disimulasikan melalui claim lokal; tujuh identitas fixture (empat peran sah, akun nonaktif dan akun tanpa keanggotaan) bukan akun Supabase Auth nyata. Uji SELECT RLS memakai SET ROLE authenticated. Hak SELECT lokal diberikan luas untuk memeriksa bahwa RLS tetap memblokir harga. Pengujian ini tidak menguji JWT gateway, PostgREST, email, autentikasi sebenarnya, concurrency banyak koneksi, browser HP, atau printer.
Tidak ada transaksi produksi dihapus, diubah, atau dipakai untuk uji negatif. Perubahan produksi hanya DDL/fungsi yang disebutkan di bawah.
